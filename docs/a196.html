Coruna 与 DarkSword 场景下的保险定损：赔的是"被证明的损失"，不是"发生过的事"

1. 执行摘要

  • 保单不是自动售货机。事件发生了、保单有效、损失真实，三件事同时成立，也未必能拿到足额赔付——决定结果的是损失能不能被还原成一串可核对的数字与凭证。
  • 核心命题一：损失有三种口径：会计口径、承保口径、诉讼口径。 三者对同一件事的计量方式不同，事件期就要按最严的那一种建账（#183）。
  • 核心命题二："因为事件"这四个字，是定损的核心争点。 一笔支出是否"因事件而起"，需要用时间、因果与必要性三条线把它钉住。
  • 核心命题三：专账必须从事件第一天开始记。 事后补的台账，在核赔时会被整体打折，而不是逐条打折。
  • 核心命题四：减损义务是双向的。 你采取措施避免损失扩大，费用通常可赔；你没有采取措施，扩大的部分可能不赔——做了什么要留痕，没做要写明原因。
  • 核心命题五：公估人不是对手。 他们的工作是还原事实、核对凭证；把你已知的事实整理好交给他们，比在谈判桌上争辩有效得多。
  • 一句话结论：保险定损质量的上限，在事件发生后的第一个星期就已经决定了；后面所有工作，都是把那一周的事实变成能被核对的材料。

2. 这一篇补哪一格

篇目讨论的是阶段

#168 解决"报案这一步不要做错"，本篇解决"报完案之后，钱怎么算清楚"。两者之间隔着的正是证据链的构建。

同时本篇与 #195（司法鉴定）有交叉：鉴定意见可以支撑因果关系，但鉴定意见不等于损失金额；金额的证明要靠单据、合同与账目。

3. 三类损失，三套证据

损失类型典型内容核心证据常见缺口
第一方直接费用响应人力、外部服务、取证鉴定、通知成本、设备更换合同、发票、工时记录、付款凭证只有内部工时表，没有外部凭证
业务中断停产、停业、交付延迟、客户流失财务基线、实际发生额、差异分析没有事前基线，无法证明"少了多少"
第三方责任客户索赔、合同违约、监管罚款索赔函、和解协议、判决或处罚决定私下和解未通知保险人

第一行最容易被低估。 内部人力的价值在核赔时通常按"额外成本"而非"机会成本"计算；如果团队本来就在发工资，这部分往往不被认可为损失。真正能赔的是"因为你的事件而额外发生的支出"，而不是"这段时间大家很辛苦"。

第二行最容易被高估。业务中断的赔付依赖基线：事件前同期的收入、订单、产能。没有基线，任何"损失了多少"都是估计。

4. 事件第一天就该开的专账

七个科目，逐笔登记，当天记，不隔夜：

  1. 响应人力：谁、哪天、多少小时、做什么；外部人员的合同与发票单独归档。
  2. 外部服务：事件响应、法律、鉴定、公关、通信（#177）。
  3. 设备与介质：替换设备、取证镜像盘、隔离环境。
  4. 通知与沟通：短信、邮件、呼叫中心、邮寄、翻译。
  5. 业务替代：临时系统、加急运输、外包产能。
  6. 鉴定与检测：检测产品、第三方检查、专家意见（#195）。
  7. 其他：差旅、加班餐、临时安保等小额但真实的支出。

每笔都要回答四个问题：什么时候发生、为什么发生、和事件什么关系、凭证在哪。 缺一项，核赔时就要额外解释；缺四项，这笔就可能被整体剔除。

专账的形式不重要（表格即可），重要的是连续、同日、可追溯。

5. 三种口径为什么对不上

口径关注点常见差异来源
会计口径报表上的费用与减值资本化、摊销、期间归属
承保口径保单责任范围内的实际支出免赔额、分项限额、等待期、除外责任
诉讼口径可主张的损害赔偿因果、可预见性、减损义务

同一笔支出，在会计上可能已经资本化，在承保上属于"维护性支出"不赔，在诉讼上可能因为"本来也要做"而不被支持。

处置纪律：建一份底层凭证账，三种口径都从它派生。 不要为三种口径分别记账——那样做，三本账迟早对不上，而对不上本身就是核赔时的大问题（#181 的"同一事实四版本"在这里同样适用）。

6. 因果链：四种混杂因素

核赔要问的是"这笔损失是不是因为这次事件"。四类因素会让这个问题变复杂：

  1. 既有问题：系统本来就有故障，事件只是让它暴露。要区分"事件造成的"与"本来就会发生的"。
  2. 同期事件：同一时期还有其它事故（供应商故障、自然灾害、市场波动）。需要时间线与影响范围的证据。
  3. 计划中的变更：有些支出本来就在预算里（系统升级、设备换新）。计划内的部分通常不赔，计划外的加急部分才可能赔。
  4. 管理决策：事件后决定更换供应商或重构系统（#185）。这是"事件后的改进"，不一定是"事件造成的损失"。

对策不是争辩，而是在专账里就把每笔支出标注"直接/间接"与"事件前是否已计划"。标注了，核赔时有据可依；不标注，就会被默认按最不利的方式解释。

7. 减损义务的两面

保单通常要求被保险人在事件后采取合理措施防止损失扩大。这条义务在实践中有两个方向：

  • 做了要留痕：隔离设备、关闭服务、加急修复、临时替代——每一件都要记录"做了什么、为什么、花了多少"。
  • 没做要解释：如果决定不采取某项措施（成本过高、风险更大、等待官方指引），要写下判断依据与决策人。

"没做"本身不一定是违约，但"没记录为什么没做"几乎一定会被减损。 这条在定向投放场景里尤其重要，因为很多处置动作都有副作用（关闭功能影响业务、隔离设备影响可用性），取舍是正常的，记录是必须的。

8. 五个节点与时限

节点你要做的典型时限来源
发现事件内部上报、启动专账保单约定的通知期限
报案向保险人提交初步通知通常为"及时"，部分保单有小时/天数限制
材料提交损失清单、凭证、时间线保险人要求的期限内
公估配合现场与账目核查由公估安排
理算与赔付确认金额、签署文件依保单与协商

第二个节点最容易出问题。 "及时"在很多保单里没有精确天数，但拖延会直接影响赔付比例；而拖延的原因往往是"等调查清楚再报"——正确的做法是先通知、后补充（#168 的报案纪律）。

9. 与公估人协作的三个要点

  1. 先给事实，后给判断。 时间线、专账、凭证、处置记录，按时间顺序整理好；判断留到他们提问时再说。
  2. 指定一个对接人。 多头对接会让同一问题得到不同回答，而这在核赔记录里是减分项（#178）。
  3. 不隐藏不利事实。 核赔过程中被发现隐瞒，后果远大于事实本身的影响；主动说明"这一段我们处理得不好"，通常比被发现要好。

公估人的报告会进入保险人的理算流程，他们写下的每一句话都可能影响最终金额，所以给他们的事实必须经得起复核。

10. 五种典型减赔与预防

情形原因预防
未及时报案超过通知期限发现即通知，细节后补
损失无法量化缺基线、缺凭证事件前保存财务基线；事件第一天开专账
因果不清混杂因素未区分专账标注直接/间接、计划内/计划外
减损不当未采取措施或未记录决策与理由书面化
除外责任损失类型不在承保范围投保时逐条核对；事件后按除外条款分类

第五行是承保阶段的问题，但要到定损阶段才暴露。 很多组织在事件后才发现"这类损失根本不赔"——这不是理赔失败，而是投保时的信息不对称（#168）。

11. 加固清单（八条）

  1. 事件第一天开专账：七个科目，当天记。
  2. 四问留痕：时间、原因、关系、凭证。
  3. 标注计划内外：事件前已计划的支出单独标出。
  4. 保存财务基线：收入、订单、产能的同口径历史数据。
  5. 决策书面化：做与不做，都写理由与决策人。
  6. 单一对接人：对保险人、公估人各指定一人。
  7. 一账派生三口径：底层凭证账一份，口径分别换算。
  8. 理赔后复盘：把这次的缺口写回下一份保单的投保问卷。

12. 八条常见误解

  1. "有保单就能赔。" 责任范围、免赔额、限额、除外责任都可能让赔付小于预期。
  2. "损失越大赔得越多。" 赔的是被证明的损失。
  3. "内部人力也是损失。" 通常只认可额外支出。
  4. "事后补台账一样。" 补的台账会被整体打折。
  5. "先查清楚再报案。" 先通知、后补充。
  6. "公估人是来挑刺的。" 他们的结论建立在你能提供的事实上。
  7. "和解可以私下进行。" 未经通知的和解可能影响赔付。
  8. "这次赔了，下次也一样。" 保单条款与承保条件每次续保都可能变化。

13. 与既有各篇的接口

  • 与 #117 对照：核赔方的核查逻辑，正是本篇要准备的方向。
  • 与 #168 衔接：承保问询与报案纪律，是定损的前置环节。
  • 与 #177 对接：外部服务的合同与发票，是直接费用的核心凭证。
  • 与 #178 对接：记录分层，决定了哪些材料可以交给公估人。
  • 与 #183 对接：诉讼口径的损失主张，与承保口径需要分别准备。
  • 与 #185 对接：事件后的更换决策，要区分"改进支出"与"事件损失"。
  • 与 #195 对接：鉴定意见支撑因果，不支撑金额。

14. 总结

保险定损的胜负手，不在谈判，而在账本：

  1. 当天开账，逐笔留痕。
  2. 一账派生，三口径换算。
  3. 因果标注，减损记录。

做到这三条，核赔时你交出去的不是一份"说明"，而是一份能被逐项核对的事实。
