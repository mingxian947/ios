DarkSword 媒体服务注入技术详解

编制日期：2026-10-13 数据来源：Google Project Zero、Apple Security Advisory、公开安全研究 性质：防御性安全研究分析（Defensive Security Research），不提供可利用代码

1. 执行摘要

DarkSword 媒体服务注入是沙箱逃逸的第二阶段核心——在 ANGLE 层获得代码执行后，攻击者将恶意指令注入 mediaserverd（iOS 媒体服务守护进程），利用其更高权限实现完整沙箱逃逸。

本文深入解析 DarkSword 媒体服务注入的技术细节。

核心内容：

  1. mediaserverd 架构与权限
  2. 媒体服务注入原理
  3. 注入技术与漏洞利用
  4. 从 mediaserverd 到系统级权限
  5. 与 Coruna 逃逸路径对比

风险等级：严重（Critical）。

2. mediaserverd 架构与权限

2.1 mediaserverd 概述

mediaserverd 是 iOS 的核心媒体服务守护进程，负责：

功能说明
音频处理播放、录制、混音
视频处理编解码、渲染
相机控制摄像头访问
AirPlay无线流媒体
媒体库音乐/视频库管理

2.2 mediaserverd 权限

权限说明
麦克风访问可录制音频
摄像头访问可拍照/录像
文件系统可访问媒体文件
网络可进行网络流媒体
沙箱比 WebContent 宽松

2.3 mediaserverd 进程模型

mediaserverd（系统守护进程）
        ├─ 音频引擎（CoreAudio）
        ├─ 视频引擎（AVFoundation）
        ├─ 编解码器（VideoToolbox/AudioToolbox）
        └─ 网络流（AirPlay/DLNA）

关键：mediaserverd 权限高于 WebContent，且沙箱限制更少。

6. 与 Coruna 逃逸路径对比

维度CorunaDarkSword
逃逸路径ANGLE → IOGPUDevice（内核）ANGLE → mediaserverd（用户态）
目标进程内核 GPU 驱动用户态媒体服务
权限级别直接到内核态先到用户态，再提权
复杂度中（单阶段）高（两阶段）
隐蔽性中高（用户态操作更隐蔽）

分析：

  • Coruna：更直接，但可能更容易被检测
  • DarkSword：更复杂，但更隐蔽，且 mediaserverd 本身有更多能力

8. 总结

DarkSword 媒体服务注入是沙箱逃逸的第二阶段：

维度现状
目标mediaserverd（媒体服务守护进程）
注入方式通过 IPC 发送特制媒体数据
漏洞类型音频/视频解析内存破坏
结果在 mediaserverd 内代码执行
后续需要内核提权才能完整沦陷

技术要点：

  1. mediaserverd 权限高于 WebContent
  2. 通过 IPC 注入特制媒体数据
  3. 音频/视频解析漏洞触发代码执行
  4. 两阶段逃逸：ANGLE → mediaserverd → 内核
