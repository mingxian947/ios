iOS 数据采集能力分析报告

编制日期：2026-10-11 数据来源：Google Cloud Threat Intelligence、Kaspersky、Citizen Lab、Apple 安全公告、公开恶意软件分析情报 性质：防御性安全研究分析（Defensive Security Research）

1. 执行摘要

iOS 数据采集能力是指攻击者在突破 iOS 安全边界（WebKit RCE → 沙箱逃逸 → 内核提权）后，对设备上的用户数据、系统信息、凭证密钥等进行系统性提取、聚合与外传的技术能力。

现代 iOS 全链条攻击（Coruna、DarkSword、Operation Triangulation、Pegasus 等）的最终目标不是"控制设备"本身，而是从设备中提取高价值数据。数据采集能力直接决定了攻击的商业价值与情报价值。

本报告系统分析 iOS 恶意软件的数据采集架构、技术机制、数据源提取方法、外传通道与反检测技术，为防御方提供全面的数据泄露风险评估框架。

核心发现：

  • 现代 iOS 攻击工具具备全设备数据采集能力——从钥匙串密钥到实时屏幕捕获
  • 采集机制从静态文件提取演进到运行时 API 钩取与实时流式采集
  • 无持久化设计使采集窗口短暂但密集——在几分钟内完成全设备数据聚合
  • 加密外传与DGA 域名使网络层检测困难
  • LLM 辅助定制使采集目标可按受害者画像动态调整

3. 静态数据采集能力

3.1 文件系统访问

内核提权后，攻击者可绕过沙箱与 Data Protection，直接访问设备文件系统。

技术细节：

  • iOS App 数据存储在各自沙箱中，但内核提权后可直接读取任意 App 的沙箱目录
  • SQLite 数据库可直接拷贝并通过 sqlite3 查询
  • 大文件可分块读取以规避内存限制

  • Operation Triangulation 通过内核漏洞直接调用 SEP 接口提取 Keychain

4. 实时流式采集能力

4.1 屏幕捕获

技术实现方式检测难度
屏幕录制调用 ReplayKit 或底层 IOSurface API中——状态栏显示录制指示器
屏幕截图UIGetScreenImage()（私有 API）或 IOSurface 直接读取低——无指示器
帧缓冲注入注入 SpringBoard 进程，钩取渲染回调高——隐蔽

应用场景：

  • 捕获用户输入的密码、PIN
  • 捕获敏感应用界面（银行、加密钱包）
  • 实时监控用户操作

4.2 音频监听

技术实现方式检测难度
麦克风录制调用 AVAudioSession + AVAudioRecorder中——状态栏显示麦克风指示器
通话录音钩取 CoreTelephony 音频流高——系统级录音
后台持续录音后台音频权限 + 静音播放中——电池消耗异常

应用场景：

  • 监听周围环境
  • 录制电话/语音通话
  • 捕获语音密码/口令

4.3 键盘记录

技术实现方式检测难度
自定义键盘扩展安装恶意键盘扩展（需用户启用）低——需用户交互
输入法钩取注入 UIKit 键盘进程，钩取按键事件高——系统级钩取
剪贴板监控持续读取 UIPasteboard中——iOS 14+ 显示剪贴板访问提示
自动填充钩取钩取 AutoFill 扩展进程高——捕获表单数据

应用场景：

  • 捕获密码、PIN、信用卡号
  • 捕获聊天内容
  • 捕获搜索查询

4.4 位置跟踪

技术实现方式检测难度
GPS 查询调用 CLLocationManager中——状态栏显示位置指示器
Wi-Fi 定位扫描附近 Wi-Fi AP 并查询 Apple 数据库高——无 GPS 指示器
基站定位查询 CTTelephonyNetworkInfo高——无指示器
历史位置读取 SignificantVisit、RoutineManager 数据库低——静态文件提取

应用场景：

  • 实时跟踪用户行踪
  • 构建位置历史档案
  • 地理围栏触发特定行为

5. 加密资产采集

5.1 加密钱包提取

目标存储位置采集方法挑战
iOS 钱包 AppApp 沙箱 + Keychain文件系统 + Keychain 提取需绕过 App 特定加密
MetaMask 等第三方钱包App 沙箱 SQLite / Keychain文件 + Keychain 提取需提取助记词/私钥
硬件钱包 AppApp 沙箱文件提取私钥通常在硬件钱包上
交易所 AppApp 沙箱 + KeychainCookie/Token 提取会话劫持

Coruna/DarkSword 案例：

  • Coruna 专门针对加密货币钱包应用，劫持扫描影像与私钥
  • 通过注入系统进程，拦截钱包 App 的加密/解密操作
  • 捕获用户扫描硬件钱包 QR 码时的影像

5.2 Secure Enclave 密钥

密钥类型保护机制可提取性说明
设备密钥（UID）SEP 硬件绑定不可提取永不离开 SEP
类密钥（Class Key）SEP 托管，受 PAC 保护需 SEP 接口绕过用于 Data Protection
生物特征模板SEP 安全区域不可提取永不离开 SEP
Passcode 派生密钥SEP 计算需 Passcode 暴力破解SEP 限速保护

攻击者策略：

  • 不直接提取 SEP 密钥（硬件不可行），而是在密钥使用时捕获
  • 通过内核漏洞钩取 Data Protection 解密操作，在明文时刻捕获
  • 或通过 Keychain 缓存读取已解密的密钥材料

6. 数据聚合与外传

6.1 数据聚合

步骤技术说明
多源合并自定义聚合脚本将文件、数据库、凭证、实时流数据合并
去重与过滤哈希校验、时间戳过滤避免重复传输已采集数据
压缩zlib / gzip减少传输量
加密AES-256-CBC / ChaCha20保护传输中的数据
分块自定义分块协议大文件分块传输，支持断点续传

6.2 外传通道

通道技术检测难度说明
HTTPSTLS 1.2/1.3 加密高——内容不可见主流外传通道
DGA 域名算法生成域名高——域名动态变化Coruna/DarkSword 使用
DNS 隧道数据编码到 DNS 查询中——异常 DNS 流量备选通道
HTTP POST明文 HTTP（较少用）低——内容可见早期工具使用
云存储上传至 Google Drive / Dropbox中——合法服务滥用部分工具使用
Telegram Bot API通过 Telegram Bot 发送数据中——合法服务滥用部分工具使用

DGA（Domain Generation Algorithm）：

  • Coruna 与 DarkSword 使用 DGA 生成伪随机域名
  • 域名基于种子 + 时间戳算法生成，攻击者与服务端同步
  • 防御方无法预知下一域名，需通过流量模式分析检测
  • 特征：大量短生命周期域名、异常 TTL、加密流量

6.3 外传策略

策略说明
分批传输高价值数据优先传输，低价值数据延后
断点续传网络中断后从断点继续，避免重复传输
流量整形模拟正常应用流量，避免突发大流量
时间窗口选择网络空闲时段传输，降低检测概率
多通道冗余主通道失败时切换备选通道

7. 反检测与反取证

7.1 采集阶段反检测

技术说明
最小权限采集仅采集目标数据，避免触发无关权限提示
指示器抑制在捕获屏幕/音频后清除状态栏指示器（需系统级钩取）
时间窗口控制在用户不活跃时段采集，减少异常行为观察
资源限制控制 CPU/网络使用率，避免性能异常

7.2 外传阶段反检测

技术说明
DGA 域名动态域名，无法预知或封禁
加密流量TLS 加密，内容不可见
流量伪装模拟正常 App 流量模式
域名前置（Domain Fronting）使用合法 CDN 域名隐藏真实目标
Fast Flux DNS域名快速切换 IP，增加封禁难度

7.3 痕迹清除（无持久化模式）

技术说明
内存驻留不写入文件系统，全部在内存中执行
日志删除删除 syslog、unifiedlog 中的相关条目
时间戳恢复恢复被修改文件的原始时间戳
临时文件清除删除 /tmp、/var/tmp 中的临时文件
内存清零退出前清零堆放的敏感数据
进程退出干净退出，不留崩溃日志

DarkSword 案例：

  • 采用"完整设备沦陷"模式——短暂驻留期间完成全设备数据采集
  • 所有操作在内存中执行，不写入持久化文件
  • 退出前清除所有痕迹，包括内存中的敏感数据
  • 传统基于文件特征的检测完全失效

10. 趋势与展望

10.1 采集能力演进

时期采集模式特点
早期（2015–2019）静态文件提取简单文件拷贝，外传明文
中期（2019–2022）静态 + 基础实时增加屏幕/键盘捕获，加密外传
当前（2022–2026）全设备 + 实时流 + 无持久化多源并行采集，DGA 外传，痕迹清除
未来AI 驱动自适应采集LLM 辅助目标识别，动态调整采集策略

10.2 关键技术趋势

  1. LLM 辅助定制：DarkSword 已使用 LLM 定制行动载荷，未来采集策略也将 AI 化
  2. 零点击采集：无需用户交互即可触发全设备数据采集（通过 iMessage/蜂窝网络）
  3. 加密资产定向采集：针对加密货币钱包的专门采集模块将成为标配
  4. 云同步数据窃取：通过 iCloud 凭证访问云端数据（跨设备采集）
  5. 供应链采集：通过恶意 SDK/库在 App 安装阶段即植入采集能力

10.3 防御演进

  1. 运行时行为 AI 检测：基于 ML 的异常行为检测，识别采集行为模式
  2. 硬件级采集指示器：不可被软件绕过的硬件级传感器激活指示
  3. Keychain 访问审计：细粒度 Keychain 访问日志与异常检测
  4. 网络流量 ML 分析：基于深度学习的 DGA/加密流量异常检测
  5. 零信任设备评估：持续评估设备安全状态，异常时降级访问权限

11. 总结

iOS 数据采集能力已从简单的文件提取演进为全设备、多维度、实时流式的系统性数据窃取能力。现代攻击工具（Coruna、DarkSword、Pegasus 等）可在几分钟内完成全设备数据聚合与外传，并通过无持久化设计使传统检测手段失效。

核心风险：

  • 内核提权 = 全设备数据沦陷
  • 无持久化设计 = 检测窗口极短
  • DGA + 加密外传 = 网络层检测困难
  • LLM 辅助 = 采集策略动态自适应

防御核心：

  1. 预防：及时更新 + Lockdown Mode
  2. 检测：运行时行为 + 网络流量 ML 分析
  3. 响应：快速隔离 + 取证 + 恢复
  4. 资产：设备可视化 + 版本基线

数据采集能力是 iOS 全链条攻击的最终价值实现环节——防御方必须在攻击链的任意环节切断攻击，而非仅在采集阶段设防。
