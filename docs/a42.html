Coruna 数据采集模块架构分析

编制日期：2026-10-13 数据来源：Citizen Lab、Amnesty Tech、Apple Security、公开安全研究 性质：防御性安全研究分析（Defensive Security Research），不提供可利用代码

1. 执行摘要

Coruna 数据采集模块是攻击链的最终目标阶段——在内核提权成功后，攻击者需要提取目标设备上的敏感数据并外传到 C2 服务器。Coruna 的采集架构采用模块化设计，支持静态提取、实时监控和加密资产窃取。

本文深入解析 Coruna 数据采集模块的架构设计。

核心内容：

  1. 采集模块总体架构
  2. 静态数据提取技术
  3. 实时监控能力
  4. 加密资产窃取
  5. 数据外传机制
  6. 与 DarkSword 采集模块对比

风险等级：严重（Critical）。

2. 采集模块总体架构

2.1 模块化设计

采集框架（Core）
        ├─ 任务调度器
        ├─ 加密模块
        ├─ 压缩模块
        └─ 外传接口

采集插件（Plugins）
        ├─ 消息采集插件
        ├─ 通话采集插件
        ├─ 联系人采集插件
        ├─ 照片/视频采集插件
        ├─ 位置采集插件
        ├─ 钥匙串采集插件
        ├─ App 特定插件（WhatsApp/Signal/Telegram）
        └─ 实时监控插件（麦克风/摄像头）

2.2 采集流程

内核提权成功
        ↓
加载采集框架
        ↓
根据 C2 指令选择采集插件
        ↓
执行数据采集
        ↓
压缩 + 加密
        ↓
外传到 C2
        ↓
清除本地痕迹

3. 静态数据提取

3.1 消息采集

数据源存储位置提取方式

邮件/var/mobile/Library/Mail/文件系统读取
WhatsApp/var/mobile/Containers/Data/Application/.../ChatStorage.sqlite数据库读取

3.2 联系人/通话记录

数据源存储位置提取方式
联系人/var/mobile/Library/AddressBook/数据库读取
通话记录/var/mobile/Library/CallHistoryDB/数据库读取

3.3 照片/视频

数据源存储位置提取方式
照片库/var/mobile/Media/DCIM/文件系统读取
截图/var/mobile/Media/PhotoData/文件系统读取

3.4 位置信息

数据源提取方式
GPS 缓存读取位置缓存文件
Wi-Fi 位置读取 Wi-Fi 位置数据库
实时位置调用位置 API

5. 加密资产窃取

5.1 钥匙串窃取

挑战：钥匙串受 Data Protection + SEP 保护

攻击方式：

内核提权成功
        ↓
读取 Data Protection 密钥（从内核内存）
        ↓
或使用 API 直接访问（root 权限）
        ↓
提取钥匙串数据
        ↓
解密（如有必要）
        ↓
外传

5.2 App 加密数据库

示例：Signal 加密数据库

Signal 数据库使用 SQLCipher 加密
        ↓
提取加密密钥（从内存 / Keychain）
        ↓
使用密钥解密数据库
        ↓
读取消息内容

5.3 端到端加密消息

挑战：Signal/WhatsApp 消息端到端加密

攻击方式：

  • 内存提取：从 App 内存中提取已解密的消息
  • 数据库窃取：提取本地数据库（消息在发送/接收时解密）
  • 屏幕捕获：截取显示的消息内容

6. 数据外传机制

6.1 外传通道

通道隐蔽性带宽使用场景
HTTPS中高常规外传
DGA 域名高中防封禁
DNS 隧道高低隐蔽外传
合法服务高中Telegram/Dropbox API

6.2 外传策略

策略说明
分批外传大数据分块传输
低速外传避免触发流量异常
优先外传高价值数据优先
失败重试网络失败时重试

6.3 反检测

技术说明
加密外传数据加密
伪装伪装成正常流量
定时选择低峰期外传
压缩减少流量特征

9. 总结

Coruna 数据采集模块是攻击链的最终阶段：

维度现状
架构模块化插件设计
静态采集消息/联系人/照片/位置
实时监控麦克风/摄像头/屏幕
加密资产钥匙串 + App 数据库
外传HTTPS + DGA + 合法服务

技术要点：

  1. 模块化设计，按需加载
  2. 静态 + 实时双模式采集
  3. 加密资产窃取是核心能力
  4. 外传采用多种隐蔽通道
