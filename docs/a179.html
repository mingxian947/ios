Coruna 与 DarkSword 场景下的报案决策：什么时候报、报什么、报到哪一步为止

1. 执行摘要

  • 确认被定向投放之后，"要不要报案"是几乎每个组织都会在三天内问出、却常常没人敢拍板的问题。本篇不讨论任何具体法域的程序，只讨论决策结构与材料粒度——这两件是组织自己就能想清楚的。
  • 核心命题一：报案不是一个动作，是四个动作：立案意愿、材料提交、后续配合、结果使用。 多数组织的混乱来自把这四件事当成一件。
  • 核心命题二：报案的动机决定了材料的粒度。 为了拿到调查资源、为了满足合规义务、为了形成对外证明、为了后续追偿——四种动机要的材料完全不同，混在一起报，一定给多。
  • 核心命题三："报了案"与"全交了"是两件事。 前者是一个法律事实，后者是一个范围问题；范围可以在规则允许内协商，而一旦交出去，通常不可撤回。
  • 核心命题四：时机上，止血优先于报案，但证据保全优先于两者。 三者的顺序错了，你可能既没止住血，也没留下证据。
  • 核心命题五：配合期最贵的不是时间，是"承诺"。 你在配合期口头说过的话，会在后半程变成你的义务。
  • 一句话结论：报案前先写清四件事：为什么报、报给谁、交什么、我准备好承受哪六项副作用。

2. 这一篇补哪一格

#170 处理跨境取证与司法协助：不同司法辖区之间的协助请求、时间尺度与不可控性。那是已经进入程序之后的事。本篇处理进入程序之前的那一步。

#105 处理平台方的合法披露边界：数据在谁手里、谁能调。那你是被请求方。本篇你是请求方。

#117 处理保险/支付/交易对手的索取：依据是合同，不是法定权力。本篇的依据是法定权力，性质完全不同——对合同方可以持续协商，对执法方通常只能就范围与方式沟通。

#167 处理合同条款（含配合义务）。本篇的"配合"往往正是合同义务被激活的地方。

#178 处理记录能否不交。本篇处理主动交什么——两者是同一组材料的两端。

3. 报案的四个真实动机

动机不是修辞，它直接决定你该准备什么。

动机成立条件需要提交的材料不成立的典型情形
获取调查资源案件可能触及有组织犯罪、跨境基础设施、需要技术手段时间线、指标、基础设施线索单点、无持续性的个案
满足合规义务所在行业/辖区存在明确的报告要求（#169）按义务清单，不多不少无明确义务却按最严标准交
形成对外证明需要对客户、合作方、监管证明"已依法处理"受案回执、处理结论用受案回执代替事实说明
为追偿铺路后续需向责任方主张（#183）可核对的损失证据、因果链把希望寄托在刑事程序上

四者的交集很小。实践中真正的问题是：一个人同时抱着四个动机去报案，结果按最严的那一套准备材料，把本不需要交的东西也交了出去。

4. 三个时机，一个顺序

方案适用情形优点风险
先止血，后报案攻击仍在持续、入口未关闭减少继续损失时间线可能因处置而改变，需靠记录补回
先报案，后止血已确认停止、但需要外部资源保全现场在等待中失去处置窗口
并行团队足够、有专人对接理论上最优现实中极易多头指挥、口径分裂

三者之上有一条绝对优先：证据保全。它必须先于处置动作（#116 的证据衰减表说的就是这件事）。具体说：在动手清理之前，先把该留的留好——日志导出、镜像、账号审计记录、原始告警。这一步做不到，后面无论报不报案、怎么止血，都缺依据。

一个常见的错误顺序是"先清理干净再说"，理由是"留着不安全"。结果是：入口关了，证据没了，解释不清损失，也解释不清为什么现在才报。

5. 材料的三级粒度

把可提交的材料分成三级，是控制范围最有效的办法。它与 #117 的三级结构相似，但依据不同：那里是合同强度，这里是法定程序下的相关性与必要性。

级别内容什么时候给不给会怎样给了会怎样
M1 结论事件性质、影响范围、已采取动作、时间线概要立案阶段通常足够可能被认为不配合风险最低，但可能不足以立案
M2 证据日志摘录、指标、账号记录、设备清单（脱敏）立案后、需要定向调查时调查无法推进数据范围扩大，需登记
M3 原始载体完整镜像、原始日志全量、未脱敏名单明确要求且无法以 M2 替代时极少数情况下影响鉴定不可撤回，且含大量无关个人信息

判断顺序建议是：先问"这个结论能不能用 M1 说清"，再问"能不能用 M2 支撑"，最后才考虑 M3。

三级的另一个用处是在内部统一口径：谁有权决定升级到 M2、谁有权决定交 M3，必须提前指定（#171 的授权结构）。现场临时决定升级的，通常是级别最高、在现场待得最短的那个人。

6. 最容易多给的三样东西

  • 完整的受害者名单。 除非调查确需，明细可以用编号 + 数量替代。多交名单的代价是双重的：既扩大了个人信息扩散面，也让"谁被盯上"成为可被二次利用的信息（#157 的名单治理是同一问题的防御侧）。
  • 内部归因意见。 "我们怀疑是某人/某组织"这类判断，在没有证据支撑时提交，等于把自己的推测变成别人的调查方向；一旦方向错误，你的可信度会被一并打折。
  • 与本案无关的系统信息。 为了让对方"了解我们的环境"，把架构图、账号体系、供应商清单一并给出。这些材料一旦进入某个流程，就离开了你的控制。

三者的共同点是：它们看起来能帮助调查，实际上主要帮助你解释自己。而解释自己，用 M1 就够。

7. 配合期：节奏与"不能承诺的事"

配合期通常比预期长。它的成本不在会议，而在每一次回应都会形成记录。

  • 节奏由你控制的部分：响应时限、材料格式、接口人、会议频率。这些应当在第一次沟通时就说明。
  • 节奏不受你控制的部分：对方内部流程、跨部门协调、技术鉴定的排期。对这些不要给出时间承诺。
  • 不能承诺的四类事：不对结果作预期；不对他人的责任作判断；不承诺"不再发生"（#173 的责任分配里，这句话的代价最大）；不承诺无限期配合（配合义务通常有边界，边界需要专业判断）。

一个技术性的建议：每次提交材料都留一份提交记录——交了什么、什么时候、给谁、依据什么要求。这份记录在半年后是唯一能回答"我们到底交过什么"的东西（#178 的材料登记）。

8. 报案的六项可预期副作用

报案不是没有代价的。提前知道代价，才能判断值不值。

副作用可预见程度能否减轻减轻方式
事件进入更长的处理周期高部分内部处置不因报案而暂停
材料范围可能扩大中是分级提交 + 每次留记录
对外口径受约束中部分先定"能说什么"再定"怎么说"（#175）
客户/合作方知情的时点提前中是提前准备通知方案（#151）
内部人员被约谈中有限提前沟通，避免"被调查"的误读（#186）
商业信息被动披露低到中部分提交前做最小化处理

最容易被低估的是第五项：内部人员第一次被外部约谈时，组织往往没有准备。这会同时损伤士气和配合质量。

9. 加固清单（八条）

  1. 报案前写一页决策备忘：四个动机中哪个是主因、依据是什么、谁批准。
  2. 先保全证据，再动处置；处置动作与证据动作分别记录。
  3. 材料分三级（M1/M2/M3），并指定每一级的批准人。
  4. 受害者名单默认用编号，除非确需明细。
  5. 归因意见不随材料提交；如被问及，说明"尚无结论"。
  6. 指定唯一对外接口人，所有约谈与材料提交经其登记。
  7. 四类承诺不出口：结果、责任、不再发生、无限期配合。
  8. 建一张提交台账：时间、对象、内容摘要、依据、批准人。

10. 八条常见误解

误解实际情况
"报案就等于把一切都交出去"报案与材料范围是两件事；范围可协商
"不报案就不会被发现"平台通知、客户投诉、供应商披露都可能先于你（#149）
"先清理干净再报案更体面"证据没了，损失与时间线都说不清
"报得越早越好"时机取决于是否已止血与是否已保全；顺序错了代价更大
"多给材料显得配合"相关性以外的东西给你带不来配合度，只带来范围
"受案回执就是对客户的证明"回执只证明你报过，不证明事实与处置
"承诺全力配合不会有问题"无边界承诺会在后半程变成压力来源
"内部人知道得越少越好"被约谈时的惊讶，比事前沟通的代价高得多

12. 总结

问题一句话答案
报案是几件事立案意愿、材料提交、后续配合、结果使用
动机影响什么决定材料粒度；四种动机不要同时按最严标准执行
三个时机的顺序证据保全 → 止血 → 报案（可并行，但保全永远最先）
材料怎么分M1 结论 / M2 证据 / M3 原始载体，逐级升级
最容易多给什么完整名单、归因意见、无关系统信息
配合期最贵的是什么承诺
值不值得报看四个动机里哪个成立，以及六项副作用你是否承受得起

报案的第一步不是打电话，是决定你要交出的范围。
