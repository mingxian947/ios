Pegasus 商业间谍软件利用 iOS 漏洞全过程分析报告

编制日期：2026-10-11 数据来源：Citizen Lab、Google Project Zero / Threat Analysis Group、Amnesty International、Forbidden Stories、Apple 安全公告、NSO 诉讼公开文件、Lookout 性质：防御性安全研究分析（Defensive Security Research） 定位：Pegasus 全版本（2016–2024）利用 iOS 漏洞的全过程技术复盘，覆盖投递、初始执行、沙箱逃逸、内核提权、持久化、数据采集、反取证全链条

1. 执行摘要

Pegasus 是由以色列 NSO Group Technologies 开发的商业间谍软件（Commercial Spyware），自 2011 年成立以来，持续向全球政府客户提供"零点击"移动设备监控能力。Pegasus 是 iOS 安全历史上最具影响力、技术最复杂、持续演进时间最长的间谍软件工具，几乎参与了 iOS 攻击技术演进的每一个关键节点。

本报告以技术全过程为主线，系统复盘 Pegasus 从 2016 年首次曝光至 2024 年的每一代利用链，逐阶段分析其投递方式、漏洞组合、利用机制、持久化策略与反检测技术，并映射至 iOS 安全架构的演进。

核心发现：

  • Pegasus 经历了 4 代主要技术演进：早期（2016）→ Trident 链（2016–2017）→ ImageIO 零点击链（2019–2021）→ M.O. 无感染模式（2022+）
  • 每一代都使用全新漏洞组合，体现 NSO 的持续研发能力
  • 从 1-click 钓鱼演进到 零点击 iMessage，再到完全无感染
  • 利用漏洞总数超过 30+ CVE，覆盖 WebKit、JSC、ImageIO、CoreGraphics、IOKit、内核等几乎所有子系统
  • 持久化从内核 hook 演进到无持久化，反取证能力持续增强
  • 2021 Pegasus Project 曝光后，NSO 被列入美国实体清单，但工具仍在扩散

4. 第一代：早期 Pegasus（2016）

4.1 投递方式

  • 1-click 钓鱼：通过短信/iMessage/WhatsApp 发送恶意 URL
  • 受害者点击链接后，Safari 加载恶意页面
  • 页面检测用户设备信息，选择对应 exploit

4.2 漏洞链：三链组合（Trident）

阶段CVE组件作用
初始执行CVE-2016-4655WebKit内核地址泄露（info leak）
沙箱逃逸CVE-2016-4656内核内核代码执行
内核提权CVE-2016-4657内核内核内存读写 → 持久化

技术细节：

  • CVE-2016-4655：WebKit 的 DOM 对象类型混淆，泄露内核基地址，绕过 KASLR
  • CVE-2016-4656：内核 IOKit 驱动 UAF，获得内核代码执行
  • CVE-2016-4657：内核内存读写原语，用于安装持久化载荷

4.3 持久化

  • 写入隐蔽 plist 文件（/Library/Preferences/com.apple.conversationproxy.plist）
  • 注册 LaunchDaemon，开机自启
  • 内核 hook 关键函数，隐藏进程/文件

4.4 能力

  • 全设备数据访问
  • 麦克风/摄像头/位置实时采集
  • 消息/通话/邮件截获
  • 加密通信截获（Signal/WhatsApp 明文捕获）

4.5 反取证

  • 41 天自毁：安装后 41 天自动卸载
  • 检测到分析环境（越狱/调试器）时不执行
  • 加密 C2 通信

5. 第二代：ImageIO 零点击尝试（2018）

5.1 投递方式

  • iMessage 附件：发送特制图片/视频附件
  • 受害者无需点击，iMessage 自动渲染附件触发漏洞
  • 这是 Pegasus 首次尝试零点击投递

5.2 漏洞链

阶段CVE组件作用
初始执行CVE-2018-4328ImageIO图片解析内存破坏
沙箱逃逸CVE-2018-4331CoreMedia媒体服务 IPC 缺陷
内核提权CVE-2018-4335内核内核内存读写

技术细节：

  • CVE-2018-4328：ImageIO 的 PNG/JPEG 解析堆溢出，在 iMessage 渲染进程中执行代码
  • CVE-2018-4331：CoreMedia 服务 IPC 缺陷，从渲染进程逃逸到系统
  • CVE-2018-4335：内核漏洞，获得 root 权限

5.3 局限

  • 此代零点击链不稳定，部分 iOS 版本无法可靠触发
  • 仍依赖 1-click 作为备选投递
  • 持久化机制与第一代类似

6. 第三代：ImageIO 零点击成熟（2019–2021）

6.1 投递方式

  • iMessage 附件零点击：特制图片/PDF/视频
  • 受害者完全无需交互，接收即触发
  • 这是 Pegasus 的标志性能力

6.2 漏洞链（2019 版本）

阶段CVE组件作用
初始执行CVE-2019-6244ImageIO图片解析内存破坏
沙箱逃逸CVE-2019-6246CoreGraphics图形渲染缺陷
内核提权CVE-2019-8649内核内核代码执行

技术细节：

  • CVE-2019-6244：ImageIO 的 TIFF 解析类型混淆，在 iMessage 渲染进程获得代码执行
  • CVE-2019-6246：CoreGraphics 的 PDF 渲染缺陷，逃逸沙箱
  • CVE-2019-8649：内核 IOKit 驱动 UAF，提权至 root

6.3 持久化

  • 内核 hook + 隐蔽 plist
  • 加密载荷存储在 /var/mobile/Library/ 隐蔽目录
  • 自毁机制保留

6.4 能力增强

  • 新增 FORCEDENTRY（2021）：复杂 PDF 触发链
  • 新增对 iOS 14+ 的适配
  • 增强反分析能力

7. FORCEDENTRY：最复杂的 iOS Exploit（2021）

7.1 背景

  • CVE-2021-30860：Citizen Lab 2021-11 披露
  • 被认为是iOS 历史上最复杂的 exploit 之一
  • 影响 iOS 13.4.5 – 15.0.4

7.2 技术机制

阶段技术
触发iMessage 接收特制 PDF 附件
初始执行CoreGraphics PDF 渲染的类型混淆 + 内存写入
沙箱逃逸跨多个子系统（未完全披露）
内核提权组合多个内核漏洞

技术亮点：

  • 单个 PDF 触发全链：PDF 文件内嵌复杂 exploit，无需外部依赖
  • 跨版本存活：影响 iOS 13–15，攻击者维护多条变体
  • iMessage 无渲染：附件在解码阶段触发，通知即可触发

7.3 影响

  • 2021-09 Apple 紧急修补（iOS 14.8 / 15.0.1）
  • 暴露 iMessage 附件解析是最高危攻击面
  • 推动 iOS 15 BlastDoor 沙箱重构

8. 第四代：M.O. 无感染模式（2022+）

8.1 背景

  • 2021 Pegasus Project 曝光后，NSO 面临巨大舆论与法律压力
  • 美国实体清单限制 NSO 获取美国技术
  • NSO 转向减少 iOS 漏洞依赖的投递方式

8.2 M.O. 技术机制

投递方式说明
网络层注入通过蜂窝信令 / DNS 重定向 / 网络中间人注入载荷
云端投递利用 iCloud 同步机制投递
物理访问通过 USB 配件 / DFU 模式
社会工程结合钓鱼 + 零点击混合

特点：

  • 减少 iOS 漏洞依赖：不依赖特定 iOS 版本漏洞
  • 网络层投递：绕过 iMessage/Web 沙箱
  • 无感染：不在设备上留下持久化文件
  • 云端协同：部分处理在云端完成

8.3 技术挑战

  • 网络层投递需要物理接近或网络位置优势
  • 云端投递需要iCloud 凭证或Apple 服务端漏洞
  • 物理访问需要接触设备

10. Pegasus 对 iOS 安全架构的影响

10.1 推动的安全改进

Pegasus 攻击Apple 响应
早期 1-click 钓鱼加强 Safari 沙箱
ImageIO 零点击ImageIO 重构 + 模糊测试
FORCEDENTRYBlastDoor（iOS 15 iMessage 沙箱重构）
内核提权PAC / PPL / KTRR 硬件保护
持久化启动链完整性校验增强
M.O. 网络投递Lockdown Mode（2022）

10.2 BlastDoor：iMessage 沙箱重构

  • iOS 15 引入 BlastDoor：iMessage 附件在独立沙箱进程中解析
  • 即使附件解析漏洞被触发，也无法逃逸到主系统
  • 显著降低 iMessage 零点击攻击成功率
  • Pegasus 后续版本减少 iMessage 依赖

10.3 Lockdown Mode

  • iOS 16 引入 Lockdown Mode：限制 WebKit JIT、复杂 Web API、iMessage 附件等
  • 检测到 Lockdown Mode 时，Pegasus 等工具主动中止
  • 高危用户（记者/活动人士/政治家）的关键防线

14. 总结

Pegasus 是 iOS 安全历史上的标杆性威胁，其技术演进反映了 iOS 攻击与防御的动态博弈：

维度Pegasus 贡献
技术复杂度从三链到 FORCEDENTRY，持续刷新 iOS exploit 复杂度上限
零点击能力推动 iOS 从零交互攻击成为现实
反取证从 41 天自毁到无持久化，持续增强
社会影响Pegasus Project 曝光推动全球对商业间谍软件的监管讨论
防御推动推动 BlastDoor、Lockdown Mode、PAC 等安全机制

核心教训：

  1. 商业间谍软件 ≠ 仅服务于政府——工具扩散与滥用不可避免
  2. 零点击攻击是现实威胁——iMessage/Web 是最高危攻击面
  3. 无持久化时代到来——传统取证手段失效
  4. 防御必须是体系——单点防御无法对抗全链条攻击
  5. 及时更新 + Lockdown Mode 是当前最有效的个人防御

Pegasus 的故事远未结束——NSO 的 M.O. 模式、工具扩散、AI 加持的未来，都将是 iOS 安全持续面临的挑战。
