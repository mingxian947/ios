编制日期：2026-10-11 数据来源：Citizen Lab、Google Project Zero / Threat Analysis Group、Lookout、Kaspersky、ESET、NSO 诉讼公开文件、Apple 安全公告、CCTV/新闻调查 性质：防御性安全研究文档（Defensive Security Research Compendium） 定位：iOS 安全领域的著名案例合集，跨案例横向对比、模式提炼、防御启示，与本仓库单案专题（Coruna / DarkSword / 三角行动 / GHOSTBLADE / 水坑攻击等）互补

1. 文档定位与使用方式

本文档不重复单案例深度分析，而是把 iOS 历史上已披露、已确认、或广为讨论的著名漏洞案例作为系统安全案例库：

  • 案例档案（Case Card）：每个案例一页式档案（时间、影响、CVE、投递、链条、归因、后果）
  • 横向对比矩阵：跨案例对比投递方式、CVE 组合、目标类型、检测对抗
  • 模式提炼：从案例中提炼 iOS 攻击的共性战术、技术与流程（TTP）
  • 防御启示：为每一类案例映射相应防御措施

阅读顺序建议：第 2 节案例时间线 → 第 3 节案例档案 → 第 4 节横向对比 → 第 5 节模式提炼 → 第 6 节防御启示。

3. 案例档案（Case Card）

3.1 Pegasus（NSO Group）

字段内容
首次曝光2016（阿联酋活动人士 Ahmed Mansour 短信钓鱼）
归因主体以色列 NSO Group，出售给政府客户
投递方式短信/WhatsApp 链接（1-click）→ iMessage 附件（0-click）
主要 CVECVE-2016-4655/4656/4657（三链）、CVE-2017-2362-2365（Trident）、CVE-2019-6244/6246/8649（ImageIO 链）、CVE-2021-30860 等
影响版本iOS 8 – iOS 15
链条阶段WebKit/JSC → 沙箱逃逸 → 内核提权 → 加密通信
持久化内核 hook + 隐藏 plist + 加密载荷
能力全设备数据、麦克风/摄像头、消息、位置、应用数据、加密通信截获
暴露事件2021 Pegasus Project（180+ 记者/活动人士/政治家）、Amnesty 诉讼、US 商务部实体清单
关键教训商业间谍软件可长期针对民主社会；供应商监管缺位

技术亮点：

  • 三链组合：WebKit（远程）→ 沙箱逃逸 → 内核提权，每步都独立 0-day
  • 零点击演进：从 2016 的钓鱼链接到 2019 的 iMessage 附件（受害者无需交互）
  • 反取证：41 天自毁机制，卸载时清理痕迹
  • 多投递：短信/iMessage/WhatsApp 均可触发

3.2 FORCEDENTRY（CVE-2021-30860）

字段内容
首次曝光2021-11（Citizen Lab）
归因主体NSO Group（据报）
投递方式iMessage 附件——零点击、可远程触发
漏洞类型CoreGraphics / PDF 解析中的内存写入
影响版本iOS 13.4.5 – 14.8，iOS 15.0.4
触发条件仅需接收特制 PDF 附件，无需打开
特点最复杂的移动端 exploit 之一——单个 PDF 触发链跨越多个子系统
后续利用与 CVE-2021-30869/30870/30792 组合成全链条
补丁iOS 14.8.1 / 15.1 紧急修补
关键教训消息类 App 附件解析是最高危的远程零点击攻击面

技术亮点：

  • PDF 复杂度：利用 CoreGraphics PDF 渲染的类型混淆 + 内存写入
  • 跨版本存活：影响 iOS 13–15，攻击者维护多条变体
  • iMessage 无渲染：附件解析发生在渲染前的解码阶段，通知即可触发

3.3 Operation Triangulation（三角行动）

字段内容
首次曝光2023-07（Kaspersky）
归因主体未确认，推测为国家背景
投递方式通过 iPhone Lightning 端口 + 恶意 USB 配件，或利用网络中间节点重定向流量
漏洞类型内核信息泄露 + 内核代码执行，跨越多个 iOS 版本
影响版本iOS 13 – iOS 16.6
持久化硬件级持久化——恶意载荷写入 SEP 之外的 NOR Flash，重启后仍能重新植入
能力静默监视、数据收集、绕过重启清除
终止条件目前仅在俄罗斯境内目标观察到（据 Kaspersky 报告）
关键教训iOS 首次被公开报告的硬件级持久化攻击；重启不再是万能清除手段

技术亮点：

  • 五漏洞链：WebKit/内核/驱动/文件系统/持久化协同
  • 物理 + 网络双投递：既可通过 USB 也可通过流量注入
  • NOR Flash 持久化：绕过 iOS 传统上"重启即清"的信任模型

3.4 checkm8（硬件缺陷）

字段内容
公开时间2019-09（axi0mX 披露）
漏洞类型BootROM 缺陷（S5L8902–S8003 芯片，即 A5–A11）
影响范围iPhone 4S – iPhone X（所有 A5–A11 设备）
不可修补BootROM 在制造时固化，Apple 无法通过固件更新修复
利用方式DFU 模式下通过 USB 发送特殊描述符触发，绕过签名校验
后果越狱（checkra1n）、解锁、取证工具（GrayKey/Cellebrite）依赖
关键教训芯片级硬件缺陷 = 永久性攻击面，即使系统更新也无法消除

技术亮点：

  • PwnedDFU：基于 checkm8 的通用越狱/工具生态
  • 取证双刃剑：Law enforcement 与攻击者都能使用

3.5 XAgent / Tailgater

字段内容
公开时间2015（LookingGlass Cybsecurity 披露）
归因主体意大利 RCS Lab / 英国 Gamma 等商业监控供应商
投递方式iMessage 附件 + WebKit（早期尝试零点击）
主要 CVECVE-2015-7034、CVE-2015-7035、CVE-2015-7036
影响版本iOS 8.4 – iOS 9.1
能力完整监视——通话、消息、位置、摄像头、麦克风
暴露事件针对意大利记者与活动人士
关键教训商业监控工具早期即已具备零点击能力；媒体监督驱动披露

3.6 Predator（Intellexa）

字段内容
公开时间2022-07（Verizon Media / Citizen Lab 报道）
归因主体以色列 Intellexa 联盟
投递方式依赖 Cytotech 与 Athena Graph——通过蜂窝信令/网络拦截
影响版本iOS 15
主要 CVE未完全披露，涉及 WebKit/内核/媒体框架
能力静默监视 + 加密通信截获
暴露事件希腊记者 Thanasis Koukakis 诉讼、欧盟议会针对委员
关键教训网络层投递（无需用户接触任何链接）成为 iOS 攻击新形态

3.7 Coruna（泄露工具包）

字段内容
公开时间2026-03（Google Cloud TI）
归因主体源自国家级/商业供应商，扩散至犯罪集团（UNC6353、UNC6691）
投递方式水坑网站 / 伪造金融门户
影响版本iOS 13 – 17.2.1
主要 CVECVE-2024-23222、CVE-2022-48503、CVE-2023-43000、CVE-2021-30952、CVE-2023-41974、CVE-2023-32434、CVE-2023-38606
利用规模5 条利用链 × 23 个漏洞，自适应选择
能力加密密钥窃取、钱包劫持、扫描影像捕获、DGA 外传
指纹识别检测到 Lockdown Mode 等保护设置主动中止
关键教训供应链扩散——高级攻击能力流入有组织犯罪

3.8 DarkSword（Coruna 后继）

字段内容
公开时间2026-03（Google Cloud TI）
归因主体UNC6353 / UNC6748 / PARS Defense（土耳其商业监控公司）
影响版本iOS 18.4 – 18.7、iOS 26 < 26.3
主要 CVECVE-2025-31277、CVE-2025-43529、CVE-2025-14174、CVE-2026-20700、CVE-2025-43510、CVE-2025-43520
链条阶段JSC 逻辑缺陷 → WebGPU 沙箱逃逸 → dyld 签名绕过 → 内核提权
持久化无持久化——短暂驻留后清除痕迹
能力全设备沦陷 + 机密数据聚合外传
AI 加持使用 LLM 定制行动载荷
关键教训现代攻击的无痕迹化 + AI 化 + 多主体共享

3.9 GHOSTBLADE

字段内容
公开时间2026（多来源）
归因主体与 Coruna/DarkSword 情报共享
主要特征复用已泄露链条 + 规避 Lockdown Mode
投递网页零日 + 水坑
主要教训锁定模式成为攻击者显式规避目标

3.10 Paragon GraphTAP

字段内容
公开时间2023（404 Media / WaPo 报道）
归因主体以色列 Paragon Solutions
客户美国陆军、HSI 等
能力零点击（iMessage）+ 应用数据全量提取
主要教训商业间谍软件已成为部分国家政府的常规执法工具

3.11 WireLurker（macOS→iOS 侧信道）

字段内容
公开时间2014-11（Palo Alto Networks）
投递方式macOS 恶意软件通过 USB 同步感染越狱 iOS 设备
主要教训跨平台感染：iOS 不是孤立攻击面，与 macOS/PC 的连接是攻击通道

3.12 Keychain 与备份滥用

字段内容
背景取证公司（Cellebrite、GrayKey）通过备份文件暴力破解 Keychain
主要教训离线备份（未加密 iCloud/本地备份）是 iOS 数据的"暗面通道"

7. 防御启示

7.1 从案例看防线被击穿的层次

层击穿案例数说明
WebKit / JSC极高（几乎所有远程案例）iOS 攻击的必争之地
沙箱高（媒体/GPU/驱动 IPC）WebContent 逃逸必选环节
PAC中（逻辑缺陷绕过，A12+）硬件保护被"绕行"而非"击碎"
内核 / IOKit极高（提权必经）攻击者投入最多的层
签名校验（AMFI/dyld）中（DarkSword 明确绕过）近年成为独立攻击面
硬件持久化（NOR Flash）低（Triangulation 首例）未来值得关注的方向
Lockdown Mode显式规避攻击者已内置中止逻辑

9. 结论

著名 iOS 漏洞案例集合揭示了移动安全的三大铁律：

  1. 没有不可击穿的层——每一层（WebKit/沙箱/PAC/内核/签名/硬件）都有被绕过或击穿的记录
  2. 攻击链是"最薄弱环节"拼接的结果——单点防御再强也需与整链协同
  3. 防御演进永远滞后攻击创新约 12–24 个月——补丁竞速与工具扩散使"及时更新"永远是最高优先级

核心建议：

  • 个人：升级 + Lockdown Mode（如高风险）+ 谨慎点击未知链接
  • 组织：MDM + 运行时检测 + DGA 网络监控 + 资产可视化 + 版本基线
  • 行业：推动供应链透明化、漏洞披露规范、商业监控工具问责
  • 研究：关注无持久化模式检测、硬件级攻击面、LLM 定制载荷识别
